## 已确定的产品要求和实现

1. Go + Win32/GDI 原生 GUI，无 WebView/Electron；Go 模块没有外部依赖。
2. 极低后台开销是持续约束。前台窗口事件和 HID 插拔驱动，5 分钟兜底扫描；避免持续重绘与重复写入。文件选择器使用短时辅助进程。
3. UI 参考 A HUB。整张设备卡片可点击，参数页锁定所选设备；没有跨品牌切换按钮或设备层级的自动切换页。
4. 配置 v2：每份配置存一套参数，程序绑定配置；未绑定程序使用默认配置。编辑中的配置与实际默认配置分离。
5. 自动切换默认开启，只在“我的配置”管理。配置拖到程序上绑定；非拖动方式是先选配置，再点程序，不是反过来。
6. 暂停自动切换时，当前代码的通用 `save()` 会先保存，再把编辑配置应用到选中设备。这是当前实现事实，后续改动需注意它也被配置页操作调用。
7. 同型号多只设备分别保存参数，允许自定义名称；重复名称附加设备短标识。
8. 顶栏显示当前配置与设备/暂停状态。右上只保留设置；标题栏 X 收入托盘，再次启动或托盘双击恢复。
9. 去掉了无意义的宣传文案和运行技术说明。改键及宏按要求排除，其他缺失功能见 features.md。

## 型号识别与设备身份必须区分

- 型号：官方 VAXEE 0x0A 查询鼠标 PID；0x1010 为 E1、0x1011 为 NP-01S V2。不是用固定本机别名猜型号。
- 独立设备身份：当前 `assignDeviceIDs()` 优先使用 VAXEE ContainerID；否则使用序列号加路径或路径。`DeviceScope()` 使用品牌和设备 ID，而非 MousePID。
- 因而“型号不依赖 ContainerID”不等于“所有设备身份完全不依赖 ContainerID”。同型号隔离已有自动测试；无稳定硬件身份时跨 USB 口/换接收器保持同一设置的能力不能保证。

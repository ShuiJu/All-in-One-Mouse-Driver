# Endgame Gear OP1w 4K v2

支持 LOD、回报率、强制传感器最高帧数（竞技模式）、Motion Sync、Power Saving 和 Deep Sleep。参数随已有程序绑定、默认配置和设备独立配置生效。

| 预设 | 回报率 | 最高帧数 | Motion Sync | Power Saving | Deep Sleep |
|---|---:|---|---|---|---|
| 日常 / 非性能 | 1000 Hz | 关闭 | 关闭 | 1 分钟 | 2 分钟 |
| 竞技 / 性能 | 4000 Hz | 开启 | 关闭 | 关闭 | 3 分钟 |

初始 LOD 为 1.0 mm，切换两种模式预设时保留已选 LOD。回报率提供 125 / 1000 / 2000 / 4000 Hz；2000 / 4000 Hz 使用无省电模式。两个定时器均支持 1–120 分钟，0 表示关闭。常规传感器模式的 LOD 为 0.7–1.7 mm；设备已在官方工具中开启 Glass Mode 时提供 1.0 / 2.0 mm，本工具保留该开关的现值。

旧 v1/v2 配置读取后会补充 Endgame 参数；`game` 或 `-game` 后缀的配置补竞技预设，其他配置补日常预设。设备专属参数仍优先于品牌参数。图片来自用户提供的 `鼠标图片/OP1w4Kv2.jpg`，构建内嵌处理后的透明 PNG。

| 写性能 / 电源组 | `0x404b80`：64 字节 `A1 15 0F 0A`；payload 实际包含 11 字节，保留官方长度字段 `0A` |
| 电量 | `0x4050c0`：`A1 B4`，64 字节回复的 `[0x10]` 为百分比；有线且低于 100% 时按官方显示充电 |

配置 raw payload 的关键偏移如下（不是整份 Feature report 的偏移）：

| raw 偏移 | 含义 / 编码 |
|---|---|
| `03` | Deep Sleep：低 7 位为分钟，bit7=1 为关闭 |
| `04` | Power Saving：同上 |
| `05` | `00`=1000 Hz 无省电，`80`=1000 Hz 省电，`04`=2000 Hz，`02`=4000 Hz，`40`=125 Hz Office |
| `06` | bit `40` 为最高传感器帧数；其他位原样保留 |
| `09` | 普通模式 code 0–10 对应 0.7–1.7 mm；Glass Mode code 1/2 对应 1.0/2.0 mm |
| `0C` | Motion Sync：0/1 |
| `6F` | Glass Mode：0/1，只读保留 |

`0x410e10` 的普通 LOD 下拉虽然包含 2.0 mm 文本，但 index 11 落入默认 code 3（1.0 mm）；本工具仅在 Glass Mode 开启时提供可逆的 2.0 mm 档位。

传感器写包的 raw 顺序为 `07 08 09 0A 0B 01 0E 0D 23..36`；性能写包顺序为 `0C 05 06 04 3D 44 4B 52 59 03 6F`。每次先读当前值，再仅修改所需字段；其他 CPI 档位、按键/滤波参数和 Glass Mode 保留。只发送发生变化的组，设备确认后再次读取六项设置核对；忙碌、失败、错误报告编号、短包和不一致的读回均不会显示成功。不会发送配对、恢复出厂或固件升级命令。

## 验证范围

自动测试覆盖两套预设的报文、所有提供的 LOD / 回报率 / Motion Sync / 最高帧数组合、定时器、其他设置保留、Glass Mode 限制、错误回复、忙碌回复、读回不一致、设备白名单、配置兼容和程序切换缓存。

2026-11-15 已完成连接中 OP1w 4K v2 的身份和设置只读验证：PID `1984`，4000 Hz、LOD 0.9 mm、最高帧数开、Motion Sync 关、Power Saving 关、Deep Sleep 3 分钟。实物的大配置回复首字节为 `A1`（请求 Report ID 为 `A0`），兼容后读回成功；该情况已有回归测试。官方工具当时在运行，未关闭它、未执行设置写入。

实物写入、真实 USB 回报间隔、实际休眠唤醒耗时与不同固件版本仍需现场验证。可在退出官方配置工具后执行只读检查：

```powershell
go run . --probe
go run ./cmd/readback
go run ./cmd/verify -brand endgame -out build/op1w-baseline.json
```

`cmd/verify` 默认只读。显式加 `-write` 后会应用测试参数并恢复基线；本次开发未执行该写入流程。
